<p>The ASDworld <a href="https://www.crowdspring.com/logo-design/900743_logo-for-asdworldcom-a-social-network-based-site-serving-families-with-autistic-children/">logo contest</a> is over, and we&#8217;ll be refining the logo a bit and updating the site soon to use it here.</p>
<p>Also, after a too-lengthy selection process, I&#8217;ve decided to build the alpha version of the test site using <a href="https://www.joomla.org/">Joomla</a>. Joomla and <a href="https://www.drupal.org/">drupal</a> are both in the running for the final site backend, but I&#8217;m hoping that the actual requirements will make the choice a bit clearer when the time comes.</p>
<p>Right now, the barebones site isn&#8217;t terribly compelling (not least of all because I haven&#8217;t updated the placeholder text!), and I&#8217;ll open up some alpha registrations late in the week. We&#8217;ll post an announcement here when we&#8217;re ready for some second-phase alpha testers who would like some early input into the overall site design and tools.</p>
<p>Remember, it&#8217;s <em>your</em> site. I&#8217;m just building a road to make the journey more comfortable.</p>
