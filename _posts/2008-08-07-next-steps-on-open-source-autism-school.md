<p>To get started, We&#8217;ve posted a project in connection with the open-source autism school at Arielle&#8217;s Project Interns site. Here is the description:</p>
<blockquote><p>Develop specifications for a web 2.0 front-end for a project to create an open-source/crowdsourced model for starting a nonprofit school for children on the autistic spectrum. The website should support and encourage contributions across all functional areas, ranging from physical &amp; regulatory requirements to administrative issues to curriculum development.</p></blockquote>
<p>We need to have a framework for capturing relevant information and sharing it so it can be used and improved. Without this, anything that is contributed doesn&#8217;t lives on a hard drive or a flat website at best; those presentations don&#8217;t really support the project&#8217;s goals. Who&#8217;s got a proposal of how to get this step moving?</p>
<p>As we noted earlier, one early step is collecting information from existing nonprofit schools that they would be willing to share. (Some measure of <a href="https://creativecommons.org/">Creative Commons</a> license should smooth that process so that they don&#8217;t feel their work is directly supporting for-profit entities.)</p>
<p>So, next actions:</p>
<p>1. Selecting and implementing a web front-end for the project that makes it easier, not harder, to organize our thoughts and collect information.<br />
2. Contacting schools for a big block of information.<br />
3. Formalizing the project so it can be more easily understood by others.<br />
4. Branding the project</p>
<p>Please help! Even a little knowledgeable guidance will go a long way at this point in the process.</p>
